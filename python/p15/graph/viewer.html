    How to read this

    Each box is a node of the provenance graph that p15d's capture built; each line is an edge, drawn in the order it happened. Columns are chapters in time order. Lanes keep the kinds apart: sockets above the process line, files below.

    Nodes

    processA process, named by its TGID and its comm. In brackets: argv[0] when it differs from the comm (a program run from /proc/self/fd/3 has the comm 3). A red ring and a tag mark a node an alert names.
    fileA file by its path, or by its identity key (o:NNNN) when it has none, such as a pipe.
    programA file whose only part in the story is that a process ran it.
    socketOne end of a connection, as local address and port → remote address and port.

    Edges

    CLONEa process forked a child (parent → child)
    EXECUTEa process ran a program file (file → process)
    OPENa process opened a file
    READ / WRITEbytes read from or written to a file or a pipe; the line is thicker for more bytes
    CONNECT / ACCEPTa process connected a socket; a listening process accepted a connection
    SEND / RECVbytes sent or received on a socket
    TCP (dotted)two sockets that are the two ends of one TCP connection, joined by sequence number

    Repeated transfers between the same two nodes are one line, with their count (×N) and bytes.

    Chapters

    The first chapter is how the start was reached: from the start, the most recent cause of each step, back in time (the cause chain). Then the start itself, then one chapter for each command it ran (each child it forked; children forked within 2 ms, such as the two ends of a pipe, share one). Last, what happened after its commands, if anything.

    What the page decides

    Nothing. Every node, edge, time and alert is p15.graph.story's output for this run. The walks are BackTracker's rule over time-stamped edges; the alerts are the four rules of p15.graph.rules, which are patterns, not verdicts. This page only lays them out and plays them.

    Keys

    ← → step, Space play or pause, Page Up Page Down chapter, Home End, O whole graph, F follow, G what comes next, Esc close.
