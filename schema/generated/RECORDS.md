- bit 1 `READ_FAILED`: a kernel or user memory read for this record failed; the affected field is empty or zero, and the failure is counted

Variable-length fields, after the fixed part in this order:

- `filename` (at most 256 bytes): bprm->filename: the path as passed to execve, or /dev/fd/N for execveat (not resolved; the resolved path joins from FILE_OPEN, Phase 2). The 256 cap is an inference, revisited with data; truncation is counted
- `argv` (at most 1024 bytes): mm->arg_start..arg_end at sched_process_exec, NUL-separated. The 1024 cap is an inference, revisited with data; truncation is counted
